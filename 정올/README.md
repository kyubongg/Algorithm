# 정올 (JUNGOL)

BaekjoonHub이 지원하지 않는 사이트라 손으로 정리한다.

## 규칙

1. 폴더는 `정올/<난이도>/<번호>. <문제명>/` 으로 만든다.
2. 그 안에 `README.md`(= `_TEMPLATE.md`를 복사해서 채운 것)와 `<문제명>.java`를 둔다.
3. 아래 표에 한 줄 추가한다.

```
정올/
├─ _TEMPLATE.md
├─ README.md
└─ 중급/
   └─ 2194. 문제명/
      ├─ README.md
      └─ 문제명.java
```
